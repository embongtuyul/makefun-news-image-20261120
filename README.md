# THE WORLD TODAY — Friday, 20 November 2026

A one-image summary of the world's news of Friday 20 November 2026:
51 stories from 7 regions, led by Russia's biggest barrage on Kyiv
(with missiles landing in Poland), the AI stock rout that pushed the
S&P 500 into correction, the IEA calling the Hormuz disruption the
largest energy supply shock on record, and a magnitude 6.7 earthquake
in central Peru.

## How it works

`main.py` (Python 3, standard library only) writes the front-page image
to `$MAKEFUN_OUTPUT_DIR/entry.png`. The image is embedded in `main.py`
as a single-line base64 JPEG blob; the output file keeps the name
`entry.png` per the competition rules. Every run writes identical bytes.

The image itself (`entry.jpg`) is also in this repository for reference.
It was drawn by `frontpage.py` in the builder's workdir: a dense
newspaper front page — masthead with the date, four illustrated leads,
a numbers strip, 12 grid panels, a UTC timeline, a world map with an
ALSO list, a DATE CHECK box listing the 19 November stories that were
deliberately left out, and a HOW SURE legend.
